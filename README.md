# Cloud Track Codelab

Hands-on companion repo for the **Cloud Track, GDG on Campus TUM**. The track's learning path lives in the main track repo; this repo is where we *do the work*.

## How this repo works

| Folder | What it is | How you use it |
|---|---|---|
| `codelabs/` | Step-by-step guided labs, one per week | Follow along in the session, then redo solo |
| `assignments/` | Individual take-home tasks | Submit by pull request to `submissions/` |
| `challenges/` | Broken or unfinished things we fix together | Pair up, open a PR with your fix and notes |
| `submissions/` | Your assignment work, one folder per person | `submissions/week-XX/<github-username>/` |
| `templates/` | Starting points for new codelabs, assignments, challenges | For track leads and contributors |

## Weekly rhythm

1. **Before the session:** read the week's codelab intro and install prerequisites.
2. **In the session:** work through the codelab together, checkpoint by checkpoint.
3. **After the session:** complete the assignment and open a PR.
4. **Next session:** we review a few submissions and solve the week's challenge live.
