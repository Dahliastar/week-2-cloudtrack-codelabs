# Week 2: Tools of the Trade

**Goal:** get comfortable with the Linux command line, Git/GitHub and Docker, the three tools everything else in cloud builds on.

**Time:** about 100 minutes live, plus the assignment.

## You will be able to
- Navigate and manipulate files from the command line
- Create a branch, commit, push and open a pull request
- Write a Dockerfile, build an image and run, inspect and clean up a container

## Prerequisites
- Git, a code editor and Docker installed
- A GitHub account
- Windows users: WSL2 (recommended) or Git Bash

Verify your setup:

```bash
git --version
docker --version
docker run hello-world
```
